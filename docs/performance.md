# 性能基线

GBLab 将信令设备规模和真实媒体并发作为两类独立指标。当前工程约束如下：

- 虚拟设备使用轻量状态机，不映射为 OS 线程、独立 socket 或 FFmpeg 进程。
- Tokio task、channel、设备启动和媒体会话必须有明确上限。
- SQLite 不进入 SIP 高频消息同步路径。
- UI 只消费批量、降频的运行快照。
- 性能结果必须使用 release 构建，在固定硬件、系统、平台和网络条件下测量。

设备调度、注册吞吐、心跳稳定性、内存占用和消息分发延迟的基准将在对应能力实现后加入 `crates/gblab-core/benches/`。未经测量的数据不作为产品指标。
